# Turnlight Icons

This folder contains the source SVG icons used by Turnlight.

Requirements:

- SVG format
- transparent background
- white monoline style
- no text
- rounded line caps and joins preferred

Runtime PNGs and the Windows ICO are generated by `prepare_assets.py` and are intentionally ignored by Git.

Expected filenames:

- `app-icon.svg`
- `bell.svg`
- `bright-mode.svg`
- `busy-stop.svg`
