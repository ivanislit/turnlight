# Security Policy

Turnlight is a local Windows utility. It does not use accounts, AI APIs, telemetry, cloud services, external services, or a background server.

Turnlight watches only the visible screen region selected by the user, compares it to local samples, and shows a local alert when a busy state becomes ready.

## Reporting Security Issues

If you find a security issue, please report it by email:

```text
ivannav.464@gmail.com
```

You can also open a GitHub issue if the report does not include sensitive information.

Please include:

- Turnlight version
- Windows version
- A short description of the issue
- Steps to reproduce, if possible
- Whether the issue affects installed builds, source usage, or both
